# Parker v0.3.1 — доменные пакеты и тонкий фасад

## Изменения

OVM-350 завершает перенос реализации в `internal`: приложение и его ресурсы,
конфигурация, HTTP, Kafka, PostgreSQL, outbox, observability и генератор сервиса.
Корневой пакет сохраняет публичные типы, сигнатуры и тонкие адаптеры.
Архитектурные тесты проверяют содержимое фасада, а не только имена файлов.

Kafka security fixture запускает `TestAuthenticatedKafka` из `internal/kafka`
и завершает работу с ошибкой, если тест отсутствует в выбранном пакете.

## Совместимость и подключение

Версия Go, зависимости, схема БД и шаблон сервиса не изменены относительно v0.3.0.
Обновление потребителей независимо и не требует изменения исходного кода:

```bash
go get github.com/overmindv/parker@v0.3.1
go mod tidy
go test -race ./...
go build ./...
```

Миграций для этого релиза нет. `replace` не нужен.
Закреплённый golangci-lint v2.11.4 запускается с Go 1.26 из `go.mod`;
при более новом локальном Go следует задать `GOTOOLCHAIN=go1.26.0`.

## Проверка опубликованного тега

```bash
make release-check RELEASE_VERSION=v0.3.1
```

Команда создаёт отдельного потребителя, скачивает опубликованный тег и проверяет
сборку, тесты и вывод версии без `replace`.
